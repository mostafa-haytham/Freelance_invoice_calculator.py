# Freelance Invoice Calculator

A simple Python program that generates a freelance invoice based on client and work details.

# Features

- Enter client information
- Select the service type
- Calculate the subtotal from hourly rate and worked hours
- Apply a percentage discount
- Calculate tax after the discount
- Calculate the final amount due
- Validate user inputs
- Display a formatted invoice

# How It Works

The program asks the user for:

- Client name
- Service type
- Hourly rate
- Hours worked
- Discount percentage
- Tax percentage

It then calculates the invoice total based on the provided information.
